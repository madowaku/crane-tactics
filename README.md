# CRANE TACTICS 🏗️♟️

## Unity試作

Unity **6000.3.9f1 / URP** のOne Night試作を追加しました。`Assets/_CraneTactics/Scenes/OneNight.unity` を開いてPlay。Battle 1 → PrizeでSlimyを獲得 → Battle 2 → 3人のEndingまでつながります。

- クリックで掴み、マウス移動で運び、クリック／Spaceで落とします。矢印／WASD、Esc一時停止にも対応。
- [完成目標の画面と方針](docs/art-direction/VISION.md)
- [環境・起動・コード構成](docs/implementation/UnityProjectContext.md)
- [実装時の検証記録](docs/implementation/VALIDATION.md)

以下は初期構想です。現在の採用仕様は[引き継ぎ](docs/implementation/CODEX_HANDOFF.md)を優先します。

クレーンゲームの「つかむ技術」を、そのまま戦術ゲームの移動ルールにする実験。

味方も敵も、盤上のユニットを直接歩かせるのではなく、クレーンでつかんで移動させる。

## Core Fantasy

**最善手が分かっていても、ちゃんと掴めるとは限らない。**

盤面を読む戦術と、クレーンを操作する身体的な腕前が同じ1手の中に入る。

- 重いユニットは持ち上げにくい
- 丸いユニットは滑りやすい
- 大型ユニットは掴みやすいが、置ける場所が少ない
- 敵を持ち上げて陣形を崩すこともできる
- 「落とす」こと自体が事故ではなく戦術になる

## v0.1 Prototype

最初はRPGにしない。1画面の対戦実験にする。

- 5×5程度の小さな盤
- 味方3体 / 敵3体
- 1ターンにクレーン操作1回
- つかむ → 持ち上げる → 運ぶ → 落とす
- 落下地点で位置が確定
- ユニットごとに重量 / 摩擦 / 掴みやすさを変える
- 勝利条件は「敵キングを指定マスから排除」など単純なものから始める

## 最初に検証したいこと

1. 狙った駒を掴む行為そのものが楽しいか
2. 戦術的に正しい手と、物理的に成功しやすい手の間に迷いが生まれるか
3. 失敗して少しズレた配置が、次の面白い局面につながるか
4. 敵ユニットを動かせることが壊れすぎず、ちゃんと戦術になるか
5. 短い動画だけで「何これ」と伝わるか

## 操作案

### Mouse / Touch
- ドラッグでクレーン移動
- 長押しで下降
- 離すとグリップ
- 再操作で上昇 / 移動 / リリース

### Camera Variant
インカメラで親指と人差し指をつまむジェスチャーを検出し、
画面内の駒を「つまんで運ぶ」版も別枝で試せる。

ただし、v0.1では通常入力を先に作る。
ゲームとして面白いことを確認してから身体入力を足す。

## Design Rule

**「戦術ゲームにクレーンを載せる」のではなく、
「クレーンでしか成立しない戦術」を探す。**
